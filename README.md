# Baldi's Basics Classic Remastered Archipelago
Oh, hi! Welcome to my **randomizer!**

**How To Install:**
* Install BepInEx (Newest works best)
* Put the "Archipelago" folder into the BepInEx/plugins folder
* When connecting to a room, go into the "Archipelago" folder in the plugins, and change the information in the "AP_Connection_Info.txt"
